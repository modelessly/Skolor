# Roadmap

Use this roadmap to group product ambition without expanding the current build scope. This is the only home for later ideas. Keep V1 narrow and move ideas forward only after the earlier phase has been validated.

## Current Version

Committed V1 scope and success criteria live only in `PRODUCT.md`. This optional roadmap contains possibilities, not implementation authorization. Move a future idea into `PRODUCT.md` and create accepted tasks before building it.

## V2: Better journeys and continuity

Potential additions:

- Walking, cycling, and public-transport time.
- Saved shortlists and optional accounts with explicit address/privacy controls.
- Inspection/regulatory-event presentation after a comparability audit.

Only consider these after V1 is usable and the core workflow is clear.

## V3: Placement context

Potential additions:

- Catchment and municipality placement information where authoritative machine-readable rules exist.
- Queue availability and admissions guidance without unvalidated probability claims.
- Evidence-grounded explanations; never AI scoring or invented facts.

Expansion should follow evidence, not enthusiasm alone.

## Parking Lot

Ideas that are interesting but not committed:

- Local school-visit notes.
- Source-update alerts.
- Validated progression/outcome links beyond compulsory school.
